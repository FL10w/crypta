УТОЧНЕНИЯ ПО ПОКРЫТИЮ
Последние две проверки каждого сгенерированного ключа выполняются только внутри if (attackResult.success).
Если атака неуспешна, они пропускаются: фактических строк [PASS]/[FAIL] будет меньше 285, а дальнейшее
соответствие следует искать по имени проверки, а не по порядковому номеру строки вывода.
Сравнение трёх методов Эйлера для 1..40 — одна проверка; восстановление пяти сообщений RSA — тоже одна.
Конструкторы RSA с Ферма и Соловеем–Штрассеном проверены только на создание объекта.
Генерация ключей, повторная генерация и восстановление сообщений RSA здесь выполняются с Миллером–Рабином.
В наборе нет проверки длины сгенерированных p/q, явной проверки устойчивости обычных RSA-ключей к атакам
Ферма/Винера, точных значений всех подходящих дробей и статистической гарантии вероятностных тестов.
Проверки диапазона результата BigInteger для Якоби, Лежандра и модульной степени не доказывают точность значения.
Каталог описывает существующий тестовый файл; исходные проверки и основная реализация не изменялись.
